# 9minecraftAPI Mod - Run Multiplatform Mods on Any Loader

9minecraftAPI Mod is a required library / API - it adds no blocks, items or gameplay of its own. Instead, it provides the shared code that many multiplatform mods are built on, so those mods can run on either major mod loader from a single codebase. If a mod on this site lists 9minecraftAPI (or the shared API) as a dependency, install this jar alongside it and it will work. Features: \t The cross-platform API layer that dozens of multiplatform mods are built on.
